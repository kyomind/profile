## 背景與核心問題探索

在初版視覺定案後，Kyo 提供實際畫面進行了多輪細部審視，主要解決了四個關鍵層次的矛盾：

### 1. 導覽選取態的演進：從「裝飾性符號」回到「純文字層級」

導覽列（Navbar）的設計經歷了多次探索：

| 探索階段 | 實作方案 | 遇到的問題／反饋 |
|---|---|---|
| **原版** | 目前頁籤深灰字＋固定底線，其他灰字 | 預設底線稍嫌生硬，希望能有更現代的標示。 |
| **階段一** | 目前頁籤主題紅字，其他灰字 | 紅色在 Navbar 頂部過於搶眼，干擾主視覺。 |
| **階段二** | 目前頁籤灰底（#f5f4f1）＋細框 | 灰底與米色頁面底（#faf9f7）亮度只差 2%，肉眼幾乎看不出色塊，反而形成髒髒的灰霧，貼身的細框干擾中文字筆畫辨識。 |
| **階段三** | 目前頁籤深灰底（#2d3748）＋淺灰字 | 產生大面積深色塊，視覺重量與卡片內的「部落格」實心按鈕打架，全頁出現兩個不同色按鈕互相爭搶注意力。 |
| **階段四** | 目前頁籤白底（#ffffff）＋中灰框（#b0aca2） | 雖然呼應大卡片材質且清楚，但框線依然帶有視覺負擔，容易讓人把視線放在「框線邊界是否與卡片陰影平衡」。 |
| **最終定案** | **純文字排版：選中深灰 `#2d3748`，未選中淺灰 `#6b7280`，hover 變深灰 `#2d3748`** | **徹底拿掉所有背景與邊框，回歸最純粹的 Typographic Hierarchy。視覺完全放鬆，主次關係自然回歸白色卡片與 Blog 按鈕。** |

### 2. 雙語切換形態：從「Segmented Control」到「單一目標 Toggle」

- **問題**：原設計在導覽列右側同時列出 `[中文]` 與 `[EN]`。在手機英文版（單字較長）下，由於橫向空間不足，加上缺了防折行規則，「中文」兩個字被硬生生擠成垂直折行（「中」在上、「文」在下），高度拉扯變形。
- **解法**：雙語網站不需要將「當前語言」列出佔位。使用者在中文頁面，唯一有意義的操作是切換英文；反之亦然。
- **定案**：
  - 中文頁只放 **`EN`** 連結；英文頁只放 **`中文`** 連結。
  - 橫向空間直接省下 50% 以上，即使在 320px 極窄螢幕下也能舒適排成一行。
  - 所有 `nav a` 加入 `white-space: nowrap` 進行防禦。

### 3. 卡片陰影：從「拖長黑尾」到「消除硬切邊」

- 最初將陰影向下放大漫射時（`0 15px 30px`），下方留白被過長的黑影吞噬，像一條拖得很長的尾巴。
- 隨後將位移收短至 2px~4px，但因為 blur 過小且濃度高，卡片正下方形成了一條生硬的「深色實體邊線」。
- **定案**：採用 `box-shadow: 0 4px 14px -2px rgba(0,0,0,.1);`。透過 `-2px` 的負 spread（收縮半徑）將硬切邊徹底消除，搭配 14px 的自然柔和羽化，使卡片擁有沉穩立體感而絕不生硬。

### 4. 字級優化與按鈕自動平衡

- 原先內文為 1rem（16px），按鈕與 nav 為 0.95rem（15.2px）。
- 為了讓閱讀體驗更清晰大方，將**內文、`h3`、`nav` 與按鈕 `.btn` 統一調升至 `1.1rem`（約 17.6px）**。
- 此調整帶來了版面上的驚喜：首頁按鈕列因為寬度自然增加，在桌機上由原本不平衡的「4 + 1」（最後一行孤立一個 X）自動換行成非常協調的「3 + 2」排列。

## 樣式契約與規範（Tokens & Rules）

### 1. 字級（純 rem 控制）
- `h1`：`2.5rem`（40px），字重 700，行高 1.2
- `h2` / `.tagline`：`1.25rem`（20px），標語字重 400，次標字重 700
- 內文主體（`p`, `li`, `.bio`）：`1.1rem`（17.6px），行高 1.6
- 次標題 `h3`：`1.1rem`（17.6px），字重 700
- 頂部導覽 `nav`：`1.1rem`，字重 400
- 連結按鈕 `.btn`：`1.1rem`，字重 500
- 外部頁尾 `footer`：繼承 body（1.1rem），顏色 `#6b7280`

### 2. 導覽互動契約
```css
nav { display: flex; align-items: center; gap: 0.5rem; margin-bottom: 12px; font-size: 1.1rem; }
nav a { color: #6b7280; text-decoration: none; padding: 0.4rem 0.5rem; min-height: 44px; display: inline-flex; align-items: center; white-space: nowrap; }
nav a:hover, nav a[aria-current] { color: #2d3748; }
nav .lang { margin-left: auto; display: flex; }
```

### 3. 主卡片與陰影
```css
.card {
  background: #fff; border: 1px solid #e8e6e1; border-radius: 12px; overflow: hidden;
  box-shadow: 0 4px 14px -2px rgba(0,0,0,.1);
}
```
